What Min3DStry Currently Is

Maintainers: Levy (@admiraly), Kevin (@Hxgg22), Elia (@Satixfied)

Min3DStry is an early-stage, open-source effort to build a native C11 port of Mindustry for Original and New Nintendo 3DS/2DS consoles using devkitARM, libctru, and Citro2D/Citro3D. Right now it is a technical foundation and rendering prototype—not a playable game yet.

Working Today

A host-tested and 3DS-compiled Citro2D 2D scene prototype (min3dstry.3dsx) showing a 36×24 tile factory slice with conveyors, turrets, a pulsing core, D-Pad/Circle Pad panning, and bottom-screen stats.

Research & Tooling

A completed Java-to-native feasibility study with a C11 simulation kernel PoC, plus automated host unit tests, Docker-based devkitARM builds, and AI PR review.

Not Built Yet

Full Mindustry gameplay, map/save loading, audio, multiplayer, and real emulator or physical 3DS hardware boot verification are still pending.
